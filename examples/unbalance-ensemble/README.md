# Unbalance-ensemble example

This directory contains an **MPAS-JEDI application input**, not a MONAN-JEDI
build/install configuration.

Use `config.yaml` as a starting point for
`mpasjedi_unbalance_ensemble.x`. Paths, dates, ensemble size and variables are
experiment-specific and must be adapted by the workflow that runs the
application.

Keeping application examples under `examples/` avoids confusing them with the
site configuration files under `config/`.
